# Content Playbook

## Episode formula (20–60s)
1. **0–3s Hook:** visual or dramatic event ("A storm just hit the capital.")
2. **3–10s Recap:** one line on last episode + show the poll result screenshot (proof).
3. **10–35s Consequence:** the winning decision happening on the map.
4. **35–50s New decision:** frame 2–3 options with visible tradeoffs.
5. **50–60s CTA:** "Poll is live. Comment your proposal. Follow to become a citizen — day N tomorrow."

Generate each brief with: `npm run nation -- episode`

## Production rules
- Pin comment: current poll, deadline, rules link.
- HUD every video: Day, Population, Treasury, Location grid cell.
- Label AI-generated content with TikTok's AI-generated content toggle (required by TikTok policy).
- Post daily at a fixed time; poll closes 20h later so each episode can show results.
- Reply to top 3 comments with video replies — cheap content + loyalty.

## Risks (read these)
- **Sustainability:** daily 3D/aerial video is heavy. Reuse the master map, batch-produce a week at a time, keep episodes 20–30s early.
- **Consistency of AI visuals:** use reference images per location; if a shot doesn't match canon, regenerate — never ship drift.
- **Polls:** verify the poll feature is available on your account; if not, use a comment-vote format (`A/B/C`, count unique users at deadline) and state that in the rules.
- **Trolls:** vetoes are logged; the rules say what is excluded.
